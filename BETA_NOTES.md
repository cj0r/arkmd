Release candidate 2 for 1.0. Windows: a file opened by double-click or Open with is the same file as one opened from the list (no second recent entry), network paths open correctly, and stored duplicate recent entries are merged; this also lets the warning for a file open in another window work. The installer removes the empty extension keys on uninstall. Includes release candidate 1: Windows installer association repair, large documents shown in parts, Android update check limited to ArkMD's releases, documentation and support statement.

This is a beta build, published for testing: it can have bugs. To go back, turn off Settings > Updates > Include beta versions and install the latest release. Android cannot install an older version over a newer one without uninstalling ArkMD first.
