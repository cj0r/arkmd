# Getting started

## Install

Download the file for your platform from the [latest release](https://github.com/cj0r/arkmd/releases/latest) and follow the steps for [Android, Windows and Linux](../README.md#install). To update, install the new release over the old one; your settings stay.

## Open a file

- **From your file manager:** choose ArkMD in **Open with**. On Android you can also use **Share** on a piece of text to open it in ArkMD as a new document.
- **From ArkMD:** tap **+** and choose **Open file…** (Ctrl+O on desktop). The same menu lists your recent files.
- **A new document:** **+** > **New file** (Ctrl+N) starts an empty `Untitled.md` in editing mode.

Every file opens in its own tab. Opening a file that is already open switches to its tab. The home screen, shown when no file is open, lists recent files as well.

## Read and edit

A file opens in reading mode. The round button at the bottom right switches between reading and editing (Ctrl+E on desktop) and keeps your place in the document. While you edit, the formatting panel floats above the keyboard; the formatting button (**Tт**) in the top bar shows or hides it.

## Save

When you change a file, a dot appears on its tab and a **Save** button appears in the top bar (Ctrl+S). **Save** writes over the original file. **More** > **Save as…** (Ctrl+Shift+S) writes a copy somewhere else. ArkMD doesn't autosave and keeps no backup copy, so keep your own backups of anything important. See [Files and saving](files-and-saving.md).

## Make it yours

The palette button opens the theme list, and **More** has the text size, the reading and editing fonts and the contrast mode. See [Themes and fonts](appearance.md).
