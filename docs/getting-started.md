# Getting started

## Install

Download the file for your platform from the [latest release](https://github.com/cj0r/arkmd/releases/latest) and follow the steps for [Android, Windows and Linux](../README.md#install). To update, install the new release over the old one; your settings stay. On Windows and Linux, **Settings** > **Check for updates now** does that for you. On Android it opens the download, and [Obtainium or ArkMD's F-Droid repository](../README.md#install) can fetch new versions in the background.

## The welcome tour

A fresh install opens a built-in welcome document that shows what ArkMD can draw, with a few things to try. Open it again any time from **More** > **Welcome tour** or the link on the home screen. It isn't a file on your device, so editing it changes nothing unless you choose **Save as** to keep a copy.

## Open a file

- **From your file manager:** choose ArkMD in **Open with**. On Android you can also use **Share** on a piece of text to open it in ArkMD as a new document.
- **From ArkMD:** tap **+** and choose **Open file…** (Ctrl+O on desktop). The same menu lists your newest files, and the clock button at the top left (Ctrl+Shift+R) opens the full Recent files list, with previews, search and pinning.
- **A new document:** **+** > **New file** (Ctrl+N) starts an empty `Untitled.md` in editing mode.

Every file opens in its own tab. Opening a file that is already open switches to its tab. The home screen, shown when no file is open, lists your recent files too.

## Read and edit

A file opens in reading mode. The round button at the bottom right switches between reading and editing (Ctrl+E on desktop) and keeps your place in the document. While you edit, the formatting panel floats above the keyboard; the formatting button (**Tт**) in the top bar shows or hides it. The list button (Ctrl+Shift+O) opens an outline of the document's headings to jump between sections, and in reading mode you can tick task checkboxes.

## Save

When you change a file, a dot appears on its tab and a **Save** button appears in the top bar (Ctrl+S). **Save** writes over the original file. **More** > **Save as…** (Ctrl+Shift+S) writes a copy somewhere else. ArkMD saves only when you ask, unless you turn on Autosave in Settings. It keeps earlier versions and a draft of unsaved work on the device, but that isn't a backup, so keep your own copies of anything important. See [Files and saving](files-and-saving.md).

## Make it yours

The palette button opens the theme list. **More** > **Settings** (Ctrl+,) has the theme, text size, reading and editing fonts, contrast mode and update options. See [Themes and fonts](appearance.md).
