ArkMD opens a Markdown file, shows it with Obsidian-style rendering, and switches to an editor with one tap. There is no vault, no plugin system and no account. "Ark" is Danish and Norwegian for "a sheet of paper".

<b>Reading</b>
• Colored headings, callouts (including foldable ones), highlights, wikilinks, tags, task lists, tables, footnotes, front matter and syntax-highlighted code blocks.
• Tick task checkboxes right in the reader.
• Find in the page, and an outline of the headings to jump between sections.

<b>Editing</b>
• A CodeMirror editor with live Markdown highlighting, a formatting panel, keyboard shortcuts for headings, lists and styles, and find and replace.
• Several files open in tabs, each with its own undo history.
• Earlier versions of a file are kept each time you save, and unsaved work is restored after a crash. Everything stays on the device.

<b>Looks</b>
• 44 dark and light themes, separate reading and editing fonts, and your own theme from a CSS file of color variables.
• Text colors meet WCAG 2.2 AA contrast by default.

<b>Private and small</b>
• Works offline, has no account and collects no data. It contacts GitHub only when you check for updates.
• About 9 MB.

<b>Please note</b>
ArkMD opens, edits and saves your Markdown files in place. Saving overwrites the original, and the earlier versions ArkMD keeps are a convenience on one device, not a backup. Keep backups of anything you can't afford to lose. ArkMD is provided without warranty.

ArkMD is developed with the help of AI coding tools (Claude). The code, tests and documentation are reviewed and tested by the maintainer, who is responsible for each release.
